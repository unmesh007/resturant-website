Indian Restaurant Website
A simple and elegant single-page website for a fictional Indian restaurant. This project showcases a clean layout for a restaurant menu, contact information, and an "about us" section. It's built with plain HTML, CSS, and a small amount of JavaScript for a user-friendly "scroll to top" feature.

Features
Single-Page Layout: All sections (Home, Menu, About, Contact) are easily accessible on a single, scrollable page.

Smooth Scrolling Navigation: A clean navigation bar allows users to jump to different sections of the page.

Interactive Menu: A visually appealing menu section with images and descriptions for each dish. The menu includes:

Chicken Curry

Paneer Tikka

Butter Naan

Biryani

Masala Dosa

Gulab Jamun

Rogan Josh

Chole Bhature

Ras Malai

Contact & About Sections: Clear and concise sections providing the restaurant's history and contact details.

Scroll to Top Button: A dynamic button that appears when a user scrolls down the page, allowing them to quickly return to the top.

🛠️ Technologies Used
HTML5

CSS3 (Internal stylesheet)

JavaScript (for DOM manipulation of the 'Top' button)

🚀 Getting Started
No special installation or setup is required. The project is a single, self-contained HTML file.

To view the website, simply follow these steps:

Clone this repository or download the resturant.html file.

Open the resturant.html file directly in any modern web browser (like Google Chrome, Firefox, or Microsoft Edge).

✏️ Customization
This project can be easily customized to fit your own restaurant's needs.

Menu Items: To add, remove, or change menu items, find the <div id="menu"> section in the resturant.html file. Each item is contained within a <div class="menu-item"> block. You can edit the dish name in the <h3> tag, the description in the <p> tag, and the image by changing the src attribute of the <img> tag.

Contact & About Information: Edit the text content within the <div id="about"> and <div id="contact"> sections to update your restaurant's details.

Styling: All CSS styles are located within the <style> tags in the <head> section of the document. You can modify colors, fonts, spacing, and hover effects here to match your brand.
